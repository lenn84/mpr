2 — Server: ceremony phase (no roster yet)

node census/serve.js <port>
The relay refuses everyone at this stage (no roster) — correct. Only the pages serve.
Open the laptop firewall for the port (runtime-only on purpose — it closes itself on reboot):
sudo firewall-cmd --add-port=<port>/tcp
Without this the phone says "can't connect to the server" even though the server runs.
Phone: install the CA. Browse to 
https://<LAN-IP>:<port>/ca.pem
(one trust warning HERE is expected), install the profile; iOS: Settings → General → About → Certificate Trust Settings → enable full trust.
Laptop browser: trust the CA too (browsers do not read runtime/tls/ — each trust store gets the CA explicitly). Firefox: Settings → Privacy & Security → Certificates → View Certificates → Authorities → delete any old "MPR pilot CA" → Import… runtime/tls/ca.pem → tick "Trust this CA to identify websites". Re-do this whenever make-cert.sh is re-run (every run mints a new CA).
Both devices load with zero certificate warnings:
https://<LAN-IP>:<port>/runtime/app/ceremony.html
Do not proceed past a warning — that is the floor.
